This guide walks you through creating a Cloudflare Workers app with CFast — from an empty directory to a running dev server that queries a D1 database.

## Prerequisites

- **Node.js 20+**
- **pnpm** (latest) — `npm install -g pnpm`
- **A Cloudflare account** — the [free tier](https://dash.cloudflare.com/sign-up) works
- **Wrangler CLI** — `npm install -g wrangler`

## Project structure

By the end of this guide your project will look like this:

<FileTree>
- my-app/
  - app/
    - entry.server.tsx — SSR stream handler
    - env.server.ts — validated Cloudflare bindings
    - root.tsx — HTML shell and error boundary
    - routes.ts — route configuration
    - schema.ts — Drizzle table definitions
    - routes/
      - home.tsx — home page with a D1 query
  - workers/
    - app.ts — Cloudflare Worker entry point
  - package.json
  - react-router.config.ts
  - tsconfig.json
  - tsconfig.cloudflare.json
  - tsconfig.node.json
  - vite.config.ts
  - wrangler.jsonc
</FileTree>

## Project Setup

<Steps>

1. **Create the project and install dependencies**

   ```bash
   mkdir my-app && cd my-app
   pnpm init
   pnpm add react react-dom react-router
   pnpm add -D @react-router/dev @cloudflare/vite-plugin vite wrangler typescript @cloudflare/workers-types @types/react @types/react-dom
   ```

   Add `"type": "module"` and scripts to `package.json`:

   ```json
   {
     "type": "module",
     "scripts": {
       "build": "react-router build",
       "dev": "react-router dev",
       "typecheck": "react-router typegen && tsc -b"
     }
   }
   ```

2. **Configure Wrangler**

   Create `wrangler.jsonc` at the project root:

   ```jsonc
   // wrangler.jsonc
   {
     "name": "my-app",
     "compatibility_date": "2025-04-01",
     "compatibility_flags": ["nodejs_compat"],
     "main": "./workers/app.ts",
     "d1_databases": [
       {
         "binding": "DB",
         "database_name": "my-app-db",
         "database_id": "local"
       }
     ]
   }
   ```

   We use `"local"` as a placeholder for `database_id`. If you plan to deploy, replace it with a real ID from `wrangler d1 create my-app-db`.

3. **Configure Vite**

   Create `vite.config.ts`:

   ```ts
   // vite.config.ts
   import { reactRouter } from "@react-router/dev/vite";
   import { cloudflare } from "@cloudflare/vite-plugin";
   import { defineConfig } from "vite";

   export default defineConfig({
     plugins: [
       cloudflare({ viteEnvironment: { name: "ssr" } }),
       reactRouter(),
     ],
   });
   ```

4. **Configure React Router**

   Create `react-router.config.ts`:

   ```ts
   // react-router.config.ts
   import type { Config } from "@react-router/dev/config";

   export default {
     ssr: true,
     future: {
       v8_viteEnvironmentApi: true,
     },
   } satisfies Config;
   ```

5. **Configure TypeScript**

   Create three config files:

   ```json
   // tsconfig.json
   {
     "files": [],
     "references": [
       { "path": "./tsconfig.node.json" },
       { "path": "./tsconfig.cloudflare.json" }
     ],
     "compilerOptions": {
       "skipLibCheck": true,
       "strict": true,
       "noEmit": true
     }
   }
   ```

   ```json
   // tsconfig.cloudflare.json
   {
     "extends": "./tsconfig.json",
     "include": [
       ".react-router/types/**/*",
       "app/**/*",
       "app/**/.server/**/*",
       "app/**/.client/**/*",
       "workers/**/*",
       "worker-configuration.d.ts"
     ],
     "compilerOptions": {
       "composite": true,
       "strict": true,
       "lib": ["DOM", "DOM.Iterable", "ES2022"],
       "types": ["vite/client"],
       "target": "ES2022",
       "module": "ES2022",
       "moduleResolution": "bundler",
       "jsx": "react-jsx",
       "baseUrl": ".",
       "rootDirs": [".", "./.react-router/types"],
       "esModuleInterop": true,
       "resolveJsonModule": true
     }
   }
   ```

   ```json
   // tsconfig.node.json
   {
     "extends": "./tsconfig.json",
     "include": ["vite.config.ts"],
     "compilerOptions": {
       "composite": true,
       "strict": true,
       "lib": ["ES2022", "DOM"],
       "target": "ES2022",
       "module": "ES2022",
       "moduleResolution": "bundler"
     }
   }
   ```

6. **Create the app shell**

   Create the Worker entry point in `workers/app.ts`:

   ```ts
   // workers/app.ts
   import { createRequestHandler } from "react-router";

   const requestHandler = createRequestHandler(
     () => import("virtual:react-router/server-build"),
     import.meta.env.MODE
   );

   export default {
     async fetch(request: Request, env: Record<string, unknown>, ctx: ExecutionContext) {
       return requestHandler(request, {
         cloudflare: { env, ctx },
       });
     },
   };
   ```

   Create the server-side rendering entry in `app/entry.server.tsx`:

   ```tsx
   // app/entry.server.tsx
   import type { AppLoadContext, EntryContext } from "react-router";
   import { ServerRouter } from "react-router";
   import { renderToReadableStream } from "react-dom/server";

   export default async function handleRequest(
     request: Request,
     responseStatusCode: number,
     responseHeaders: Headers,
     routerContext: EntryContext,
     _loadContext: AppLoadContext
   ) {
     const body = await renderToReadableStream(
       <ServerRouter context={routerContext} url={request.url} />
     );

     responseHeaders.set("Content-Type", "text/html");
     return new Response(body, {
       headers: responseHeaders,
       status: responseStatusCode,
     });
   }
   ```

   Create the root layout in `app/root.tsx`:

   ```tsx
   // app/root.tsx
   import {
     isRouteErrorResponse,
     Links,
     Meta,
     Outlet,
     Scripts,
     ScrollRestoration,
   } from "react-router";

   export function Layout({ children }: { children: React.ReactNode }) {
     return (
       <html lang="en">
         <head>
           <meta charSet="utf-8" />
           <meta name="viewport" content="width=device-width, initial-scale=1" />
           <Meta />
           <Links />
         </head>
         <body>
           {children}
           <ScrollRestoration />
           <Scripts />
         </body>
       </html>
     );
   }

   export default function App() {
     return <Outlet />;
   }

   export function ErrorBoundary({ error }: { error: unknown }) {
     let message = "Oops!";
     let details = "An unexpected error occurred.";

     if (isRouteErrorResponse(error)) {
       message = error.status === 404 ? "404" : "Error";
       details =
         error.status === 404
           ? "The requested page could not be found."
           : error.statusText || details;
     } else if (import.meta.env.DEV && error instanceof Error) {
       details = error.message;
     }

     return (
       <main style={{ padding: "2rem", fontFamily: "system-ui, sans-serif" }}>
         <h1>{message}</h1>
         <p>{details}</p>
       </main>
     );
   }
   ```

   Define your routes in `app/routes.ts`:

   ```ts
   // app/routes.ts
   import { type RouteConfig, index } from "@react-router/dev/routes";

   export default [
     index("routes/home.tsx"),
   ] satisfies RouteConfig;
   ```

7. **Set up your environment with `@cfast/env`**

   ```bash
   pnpm add @cfast/env
   ```

   Create `app/env.server.ts`:

   ```ts
   // app/env.server.ts
   import { defineEnv } from "@cfast/env";

   export const env = defineEnv({
     DB: { type: "d1" },
   });

   export type Env = ReturnType<typeof env.get>;
   ```

   `defineEnv` gives you a validated, fully typed environment object. If the `DB` binding is missing, you get a clear error at startup instead of an obscure crash at query time.

   The `.server.ts` suffix tells the React Router bundler to keep this file out of client bundles. Bindings are server-only — they do not exist in the browser.

8. **Define your schema**

   ```bash
   pnpm add @cfast/db drizzle-orm
   ```

   Create `app/schema.ts`:

   ```ts
   // app/schema.ts
   import { sqliteTable, text, integer } from "drizzle-orm/sqlite-core";

   export const posts = sqliteTable("posts", {
     id: integer("id").primaryKey({ autoIncrement: true }),
     title: text("title").notNull(),
     content: text("content").notNull(),
     createdAt: integer("created_at", { mode: "timestamp" }).notNull(),
   });
   ```

9. **Create your first route**

   Create `app/routes/home.tsx`:

   ```tsx
   // app/routes/home.tsx
   import { createDb } from "@cfast/db";
   import { desc } from "drizzle-orm";
   import * as schema from "../schema";
   import { posts } from "../schema";
   import { env } from "../env.server";
   import type { Route } from "./+types/home";

   export async function loader({ context }: Route.LoaderArgs) {
     env.init(context.cloudflare.env);
     const { DB } = env.get();

     const db = createDb({
       d1: DB,
       schema,
       grants: [],
       user: null,
       cache: false,
     });

     const allPosts = await db
       .unsafe() // Skip permissions for now
       .query(posts)
       .findMany({
         orderBy: desc(posts.createdAt),
         limit: 20,
       })
       .run({});

     return { posts: allPosts };
   }

   export default function Home({ loaderData }: Route.ComponentProps) {
     const { posts } = loaderData;

     return (
       <div>
         <h1>My App</h1>
         {posts.length === 0 ? (
           <p>No posts yet.</p>
         ) : (
           <ul>
             {posts.map((post) => (
               <li key={post.id}>
                 <h2>{post.title}</h2>
                 <p>{post.content}</p>
               </li>
             ))}
           </ul>
         )}
       </div>
     );
   }
   ```

   This uses `db.unsafe()` to skip permission checks while getting started. Once you add `@cfast/permissions`, you can replace this with proper role-based access control.

10. **Create the D1 database and run locally**

    Apply your schema using raw SQL against the local D1 instance:

    ```bash
    wrangler d1 execute my-app-db --local --command \
      "CREATE TABLE IF NOT EXISTS posts (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        content TEXT NOT NULL,
        created_at INTEGER NOT NULL
      );"
    ```

    Start the dev server:

    ```bash
    pnpm dev
    ```

    Open [http://localhost:5173](http://localhost:5173) and you should see your app running against a local D1 database.

    <Aside type="tip">
      `react-router dev` starts Wrangler under the hood, so your app runs in the actual Workers runtime — not a Node.js process. This means any Workers-incompatible code will fail here, not just in production.
    </Aside>

</Steps>

## Next Steps

You now have a working Cloudflare Workers app with type-safe bindings and a D1 database. From here:

- **[Tutorial: Build a Team Blog](../tutorial/01-setup/)** — Walk through building a complete app with authentication, permissions, and an admin panel.

As you build out your app, the typical progression is:

1. **`@cfast/permissions`** — Define roles and grants so queries are permission-aware.
2. **`@cfast/auth`** — Add magic-link email and passkey authentication.
3. **`@cfast/actions`** — Structure your mutations with multi-action routes.
4. **`@cfast/ui`** — Use permission-aware components that automatically hide actions users cannot perform.
5. **`@cfast/admin`** — Generate an admin panel from your Drizzle schema.
