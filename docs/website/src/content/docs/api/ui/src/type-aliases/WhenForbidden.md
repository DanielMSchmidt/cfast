> **WhenForbidden** = `"hide"` \| `"disable"` \| `"show"`

Defined in: [packages/ui/src/types.ts:243](https://github.com/DanielMSchmidt/cfast/blob/9cc20c03745c81d3c35a3df2245735fc00e8f884/packages/ui/src/types.ts#L243)

Behavior when an action is not permitted.
- `"hide"`: component is not rendered
- `"disable"`: component is rendered but disabled
- `"show"`: component is rendered and interactive regardless
