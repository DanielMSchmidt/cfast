# @cfast/ui Design

## Goal

Permission-aware React components. A button wraps an action — it auto-hides when the user lacks all permissions, disables when permissions are partial, and submits when permitted. Zero permission-checking UI code for developers.

## Architecture

Two layers:

### Layer 1: Headless Core (`@cfast/ui`)

- **`useActionStatus(descriptor, actionName)`** — thin wrapper around `useActions()` from `@cfast/actions/client`. Extracts `{ permitted, invisible, reason, submit, pending, data, error }` for a single action.
- **`PermissionGate`** — conditionally renders children based on an action's permission status. Props: `action` (ClientDescriptor), `actionName` (string), `input?`, `fallback?`, `children`.
- **`createUIPlugin(components)`** — factory that receives primitive UI components (button, tooltip, confirmDialog) and returns permission-aware compound components (`ActionButton`).

### Layer 2: Joy UI Plugin (`@cfast/ui/joy`)

Passes Joy UI primitives into `createUIPlugin()`:
- `Button` from `@mui/joy`
- `Tooltip` from `@mui/joy`
- `Modal` + `ModalDialog` for confirm dialog

Exports: `ActionButton` (and re-exports `PermissionGate` from core).

## Plugin API

```typescript
type UIPluginComponents = {
  button: ComponentType<ButtonProps>;
  tooltip: ComponentType<TooltipProps>;
  confirmDialog: ComponentType<ConfirmDialogProps>;
};

type ButtonProps = {
  onClick: () => void;
  disabled: boolean;
  loading: boolean;
  children: ReactNode;
};

type TooltipProps = {
  content: string;
  children: ReactNode;
};

type ConfirmDialogProps = {
  open: boolean;
  onConfirm: () => void;
  onCancel: () => void;
  message: string;
};
```

`createUIPlugin` takes these and returns `{ ActionButton }` — a component that:
- Calls `useActionStatus()` internally
- Returns `null` when `invisible` (unless `whenForbidden="show"`)
- Renders disabled button + tooltip when `!permitted`
- Renders confirm dialog when `confirmation` prop is set
- Renders normal button that calls `submit()` on click

## ActionButton Props

```typescript
type ActionButtonProps = {
  action: ClientDescriptor;
  actionName: string;
  input?: Serializable;
  whenForbidden?: "hide" | "disable" | "show"; // default: "disable"
  confirmation?: string;
  children: ReactNode;
  // Pass-through to underlying button
  color?: string;
  variant?: string;
  size?: string;
  startDecorator?: ReactNode;
  endDecorator?: ReactNode;
};
```

## PermissionGate Props

```typescript
type PermissionGateProps = {
  action: ClientDescriptor;
  actionName: string;
  input?: Serializable;
  fallback?: ReactNode;
  children: ReactNode;
};
```

When `invisible` → renders `fallback` (or nothing). When `permitted` → renders `children`. When `!permitted && !invisible` → renders `fallback` (partial permissions = not enough).

## Dependencies

- `@cfast/actions` — `useActions()`, `ClientDescriptor`, `ActionHookResult`
- `@cfast/permissions` — types only (already transitive via actions)
- `@mui/joy` — peer dependency (optional, only for `@cfast/ui/joy`)
- `react` — peer dependency
