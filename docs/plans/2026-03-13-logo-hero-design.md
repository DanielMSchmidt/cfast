# Logo & Hero Background Design: Speed Cloud

## Concept

A hexagonal shield (Cloudflare's signature shape) with speed lines streaming off the right edge, communicating "Cloudflare, but faster." Orange/amber color palette staying close to Cloudflare's brand.

## Logo Mark

- Hexagonal shield, slightly rounded corners, tilted ~5deg clockwise for forward motion
- Simplified cloud silhouette inside (two bumps top, flat bottom)
- 3-4 horizontal speed lines off the right edge, tapering thick-to-thin, slightly curved
- Gradient: `#F6821F` (CF orange) left -> `#FBAD41` (bright amber) right
- Cloud cutout is transparent
- Speed lines fade to transparent at tips

## Text Lockup

- "CFast" beside the mark in clean sans-serif (Inter/system)
- "C" bold + colored `#F6821F`, "Fast" regular weight in current text color
- Variants: full lockup (navbar), mark only (favicon), text only (CLI/badges)

## Hero Background

- Dark background `#0f1117`
- Soft amber radial glow centered on logo, ~40% opacity
- 5-7 elongated horizontal speed streaks from center-left to right, orange->amber gradient at 10-15% opacity
- Faint dot-grid at 3-5% opacity for tech/infra feel
- Logo centered, tagline + CTAs below
